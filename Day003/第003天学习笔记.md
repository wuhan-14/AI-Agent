### 任务 1｜两门语言各写一个 BMI 计算器，输出数值与等级

**Java**（存为 `Bmi.java`）

```java
public class Bmi {
    public static void main(String[] args) {
        double h = 1.75, w = 68;
        double bmi = w / (h * h);
        String level = bmi < 18.5 ? "偏瘦" : bmi < 24 ? "正常" : bmi < 28 ? "偏胖" : "肥胖";
        System.out.printf("BMI=%.1f %s%n", bmi, level);
        System.out.println("-7 / 2 = " + (-7 / 2) + ", -7 % 2 = " + (-7 % 2));
        System.out.println("5 / 2 = " + (5 / 2) + ", 5 / 2.0 = " + (5 / 2.0));
    }
}
```

```bash
javac Bmi.java && java Bmi
```

应该看到：`BMI=22.2 正常 / -7 / 2 = -3, -7 % 2 = -1`

**Python**（存为 `bmi.py`）

```python
h, w = 1.75, 68
bmi = w / h ** 2
level = "偏瘦" if bmi < 18.5 else "正常" if bmi < 24 else "偏胖"
print(f"BMI={bmi:.1f} {level}")
print("-7 // 2 =", -7 // 2, ", -7 % 2 =", -7 % 2)
print("链式比较:", 0 < bmi < 30)
```

```bash
python bmi.py
```

应该看到：`BMI=22.2 正常 / -7 // 2 = -4 , -7 % 2 = 1`

### 任务 2｜对比 -7 // 2 与 -7 % 2 在两语言中的结果并解释

```java
System.out.println(-7 / 2);     // -3，向零截断
System.out.println(-7 % 2);     // -1，符号跟被除数
```
```python
print(-7 // 2)                  # -4，向下取整
print(-7 % 2)                   # 1，符号跟除数
```
为什么重要：分页、分片、哈希取模都依赖这个规则，两语言混用会让「第 -1 页」这种问题冒出来。

## 三、今天只要记住这 3 句

1. 运算符按优先级结合：算术 > 比较 > 逻辑 > 赋值；拿不准就加括号，括号不丢人。
2. `+` 对字符串是拼接，对数字是加法，从左到右结合，`"a" + 1 + 2` 得 `a12`，`1 + 2 + "a"` 得 `3a`。
3. RAG 里算相似度阈值、成本估算（token × 单价）全靠这些；Java 用 double 算钱会丢精度，金额必须用 BigDecimal。

> 今天最容易踩的坑：Java 的 `%` 结果符号跟被除数走（-7 % 2 = -1），Python 跟除数走（-7 % 2 = 1），做分片、取模索引时会对不上。
