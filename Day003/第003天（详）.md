## 五、概念详解

### Java 线 · 运算符与表达式

#### 1. 算术、关系、逻辑、位运算符

- **是什么**：加减乘除与取模：`+ - * / %`。
- **为什么重要**：注意 Java 的 `/` 在整数间是整除，Python 的 `/` 永远返回浮点。
- **怎么用 / 坑**：需要整除用 `//`（Python）或先转 double（Java）。
- **今天的最低要求**：能指着 `运算符与表达式` 里的具体一行说清它在干什么。

#### 2. 自增自减与赋值运算符

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「两门语言各写一个 BMI 计算器，输出数值与等级」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。

#### 3. 三元表达式与运算符优先级

- **是什么**：`条件 ? 值1 : 值2` 的简写分支。
- **为什么重要**：只适合两个分支且表达式简单的情况。
- **怎么用 / 坑**：嵌套三元可读性极差；Python 写作 `a if cond else b`。

#### 4. 整数除法与取模的符号规则

- **是什么**：求余数，`%`。
- **为什么重要**：判断奇偶、循环取下标、哈希分桶都用它。
- **怎么用 / 坑**：Java 的 `-7 % 2` 得 -1；Python 得 1（向下取整）。跨语言移植时会踩。

### Python 线 · 运算符与链式比较

#### 1. // 整除、** 幂、% 取模

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。
- **今天的最低要求**：把这组清单里的每一项都能在自己机器上找到对应位置。

#### 2. 链式比较 0 < x < 10

- **是什么**：Python 支持 `0 < x < 10`，等价于 `0 < x and x < 10`。
- **为什么重要**：读起来像数学，减少重复写变量。
- **怎么用 / 坑**：Java 不支持，必须拆成两个条件用 `&&` 连接。

#### 3. and/or 的短路与返回值

- **是什么**：`and`/`or` 在结果确定时不再计算右边。
- **为什么重要**：常用于「先判空再取属性」：`if user and user.name`。
- **怎么用 / 坑**：Python 的 `and` 返回的是操作数本身，不是 True/False。

#### 4. int()/float()/str() 类型转换

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | Java 整数溢出静默回绕不报错 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |

> **40 分钟规则**：一个问题卡超过 40 分钟，记进「待解决清单」继续往下走。周日集中处理。零基础最常见的失败不是学不会，是被一个环境问题卡三天。
