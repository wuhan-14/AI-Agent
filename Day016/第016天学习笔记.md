### 任务 1｜用 += 和 StringBuilder 各拼接 1 万次，记录耗时

**Java**（存为 `JoinDemo.java`）

```java
import java.util.StringJoiner;

public class JoinDemo {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= 5; i++) {
            sb.append("chunk-").append(i).append(";");
        }
        System.out.println("StringBuilder: " + sb);

        StringJoiner sj = new StringJoiner(", ", "[", "]");
        for (int i = 1; i <= 3; i++) sj.add("doc" + i);
        System.out.println("StringJoiner: " + sj);

        long t1 = System.nanoTime();
        String s = "";
        for (int i = 0; i < 20000; i++) s += i;
        long t2 = System.nanoTime();
        StringBuilder b = new StringBuilder();
        for (int i = 0; i < 20000; i++) b.append(i);
        long t3 = System.nanoTime();
        System.out.println("加号 " + (t2 - t1) / 1000000 + "ms, StringBuilder " + (t3 - t2) / 1000000 + "ms");
    }
}
```

```bash
javac JoinDemo.java && java JoinDemo
```

应该看到：`StringBuilder: chunk-1;chunk-2;... / 加号明显更慢`

**Python**（存为 `join_demo.py`）

应该看到：`join: chunk-1;chunk-2;... / 加号明显更慢`

## 三、今天只要记住这 3 句

1. `StringBuilder` 是可变的字符序列，拼接不产生新对象，循环里拼字符串必须用它；`StringJoiner` 专门解决「带分隔符拼接 + 前后缀」。
2. `String` 适合少量拼接和常量，`StringBuilder` 适合循环内拼接（非线程安全但快），`StringBuffer` 线程安全但慢，日常用 StringBuilder。
3. RAG 拼上下文就是把 top-k 段文本用固定模板拼成一个大字符串，这一步的效率直接决定首字延迟。

> 今天最容易踩的坑：`StringBuilder` 的 `append` 返回自身，可以链式调用，但别把它当 String 传给需要 String 的方法，要 `toString()`。
