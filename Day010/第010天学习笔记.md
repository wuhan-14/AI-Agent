### 任务 1｜把前面写过的「求最值」「排序」「打印矩阵」抽成方法/函数

**Java**（存为 `Methods.java`）

```java
public class Methods {
    static int sum(int... nums) {
        int s = 0;
        for (int n : nums) s += n;
        return s;
    }

    static double avg(int[] a) {
        return (double) sum(a) / a.length;
    }

    public static void main(String[] args) {
        int[] data = {80, 92, 71};
        System.out.println("总分=" + sum(data));
        System.out.println("平均=" + avg(data));
        System.out.println("可变参数=" + sum(1, 2, 3, 4));
    }
}
```

```bash
javac Methods.java && java Methods
```

应该看到：`总分=243 / 平均=81.0 / 可变参数=10`

**Python**（存为 `funcs.py`）

```python
def total(*nums):
    return sum(nums)

def avg(nums):
    return total(*nums) / len(nums)

data = [80, 92, 71]
print("总分=", total(*data))
print("平均=", avg(data))
print("可变参数=", total(1, 2, 3, 4))
```

```bash
python funcs.py
```

应该看到：`总分= 243 平均= 81.0 可变参数= 10`

### 任务 2｜写一个方法，接收数组返回平均值，处理空数组

```java
static boolean isValid(int score) {
    return score >= 0 && score <= 100;
}
static String level(int score) {
    if (!isValid(score)) return "非法";
    return score >= 90 ? "A" : score >= 60 ? "及格" : "不及格";
}
```
```python
def is_valid(score):
    return 0 <= score <= 100

def level(score):
    if not is_valid(score):
        return "非法"
    return "A" if score >= 90 else "及格" if score >= 60 else "不及格"
```
拆方法的判断标准：这个方法能不能用一句话说清它做什么。说不清，就还得再拆。

## 三、今天只要记住这 3 句

1. 方法把一段逻辑封装成可复用的单元：修饰符 + 返回值类型 + 方法名 + 参数列表 + 方法体，一个方法只做一件事。
2. 形参是方法定义里的变量，实参是调用时传进去的值；Java 是值传递，传对象传的是引用的副本，所以方法内改对象内容会影响外面，重新赋值引用则不会。
3. Agent 的每个工具就是一个函数：名字、参数、返回值、失败时抛什么，定义清楚模型才敢调。

> 今天最容易踩的坑：Java 方法签名只看「方法名 + 参数类型」，返回值不同不算重载，写了也编译不过。
