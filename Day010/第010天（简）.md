## 一、Java 线 · 方法定义与调用

**核心知识点**：

- 方法的完整格式：修饰符 返回值 方法名(参数)
- 形参与实参、返回值
- 方法重载（同名不同参）
- 方法的内存执行流程

## 二、Python 线 · 函数定义与调用

**核心知识点**：

- def 定义、return 返回值
- 位置参数与关键字参数
- 默认参数的坑（可变默认值）
- 函数即对象，可赋值可传参

## 三、动手任务

1. 把前面写过的「求最值」「排序」「打印矩阵」抽成方法/函数
2. 写一个方法，接收数组返回平均值，处理空数组
3. 演示 Java 方法重载与 Python 默认参数

## 四、验收标准

- [ ] 每个方法只做一件事，名字能读出用途
- [ ] 知道 Java 只有值传递

## 五、常见坑

Java 方法签名不含返回值，只有返回值不同不算重载；Python 默认参数不要用 [] 或 {}。
