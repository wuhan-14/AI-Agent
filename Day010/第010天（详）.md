## 五、概念详解

### Java 线 · 方法定义与调用

#### 1. 方法的完整格式：修饰符 返回值 方法名(参数)

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。
- **今天的最低要求**：能指着 `方法定义与调用` 里的具体一行说清它在干什么。

#### 2. 形参与实参、返回值

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「把前面写过的「求最值」「排序」「打印矩阵」抽成方法/函数」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。

#### 3. 方法重载（同名不同参）

- **是什么**：类里的函数，把一段逻辑命名后复用。
- **为什么重要**：拆方法的标准：这段代码能用一句话说清在干什么。
- **怎么用 / 坑**：一个方法只做一件事；参数超过 4 个考虑封装成对象。

#### 4. 方法的内存执行流程

- **是什么**：类里的函数，把一段逻辑命名后复用。
- **为什么重要**：拆方法的标准：这段代码能用一句话说清在干什么。
- **怎么用 / 坑**：一个方法只做一件事；参数超过 4 个考虑封装成对象。

### Python 线 · 函数定义与调用

#### 1. def 定义、return 返回值

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「把前面写过的「求最值」「排序」「打印矩阵」抽成方法/函数」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。
- **今天的最低要求**：能指着 `函数定义与调用` 里的具体一行说清它在干什么。

#### 2. 位置参数与关键字参数

- **是什么**：调用时用 `f(name="x")` 指定参数名，顺序随意。
- **为什么重要**：参数多时可读性大幅提升，也避免传错位置。
- **怎么用 / 坑**：位置参数必须在关键字参数之前。

#### 3. 默认参数的坑（可变默认值）

- **是什么**：定义时给参数默认值，调用可省略。
- **为什么重要**：减少重载；但默认值在定义时求值一次。
- **怎么用 / 坑**：**绝不要用可变对象当默认值**（`def f(x=[])`），所有调用共享同一个列表。

#### 4. 函数即对象，可赋值可传参

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | Java 方法签名不含返回值，只有返回值不同不算重载 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |

> **40 分钟规则**：一个问题卡超过 40 分钟，记进「待解决清单」继续往下走。周日集中处理。零基础最常见的失败不是学不会，是被一个环境问题卡三天。
