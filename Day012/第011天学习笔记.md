### 任务 1｜写一个方法交换两个 int，验证外部没变

**Java**（存为 `Varargs.java`）

```java
import java.util.Arrays;

public class Varargs {
    static String join(String sep, Object... parts) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < parts.length; i++) {
            if (i > 0) sb.append(sep);
            sb.append(parts[i]);
        }
        return sb.toString();
    }

    public static void main(String[] args) {
        System.out.println(join("-", "a", "b", "c"));
        System.out.println(join(", ", 1, 2.5, true));
        int[] arr = {1, 2, 3};
        System.out.println(join("+", Arrays.stream(arr).boxed().toArray()));
    }
}
```

```bash
javac Varargs.java && java Varargs
```

应该看到：`a-b-c / 1, 2.5, true / 1+2+3`

**Python**（存为 `args_kwargs.py`）

```python
def show(*args, **kwargs):
    print("位置参数:", args)
    print("关键字参数:", kwargs)

show(1, 2, 3, name="qa", debug=True)

def add(a, b):
    return a + b

pair = (2, 3)
print("解包调用:", add(*pair))
```

```bash
python args_kwargs.py
```

应该看到：`位置参数: (1, 2, 3) / 关键字参数: {'name': 'qa', 'debug': True} / 解包调用: 5`

### 任务 2｜写一个方法修改数组第一个元素，验证外部变了

```java
static void change(int x) { x = 999; }
static void change(int[] a) { a[0] = 999; }

int n = 1;
change(n);
System.out.println(n);        // 1，值传递，改不动
int[] arr = {1};
change(arr);
System.out.println(arr[0]);   // 999，改的是堆里的对象
```
```python
def change_num(x):
    x = 999

def change_list(a):
    a[0] = 999

n = 1; change_num(n); print(n)        # 1
arr = [1]; change_list(arr); print(arr)  # [999]
```
结论：**能不能改到外面，取决于你改的是「变量指向」还是「对象内容」**，跟语言无关。

## 三、今天只要记住这 3 句

1. 可变参数让方法接收任意个同类型实参，编译期会包成数组；一个方法只能有一个可变参数，且必须在参数列表最后。
2. `int...` 与 `int[]` 在调用上兼容，但重载时优先匹配固定参数版本；`Object...` 能接任意类型，代价是失去类型检查。
3. 调用模型 API 时参数很多且可选，SDK 基本都用 `**kwargs` 透传；看懂签名才知道哪些参数能传。

> 今天最容易踩的坑：`*args` 之后不能再跟普通位置参数，否则调用时永远匹配不到——语法直接报错。
