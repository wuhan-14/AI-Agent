## 一、Java 线 · HashMap 与 Map 接口

**核心知识点**：

- put/get/containsKey/remove
- 遍历 entrySet 与 keySet
- computeIfAbsent 的常用场景
- HashMap 无序、LinkedHashMap 保序

**参考代码**（先手敲，再改 3 处）：

```java
Map<String, Integer> cnt = new HashMap<>();
for (String w : words) {
    cnt.merge(w, 1, Integer::sum);
}
```

## 二、Python 线 · 字典 dict

**核心知识点**：

- d[key] 与 d.get(key, default) 的区别
- items()/keys()/values()
- 嵌套字典表示结构化数据
- 字典推导式

**参考代码**：

```python
from collections import Counter
cnt = Counter(words)
print(cnt.most_common(10))
```

## 四、验收标准

## 五、常见坑

HashMap 的 key 必须重写 hashCode/equals；Python 的 dict 键必须可哈希，list 不能当键。
