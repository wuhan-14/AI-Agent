### 任务 1｜统计一段英文文本的词频并按次数排序输出前 10

**Java**（存为 `MapDemo.java`）

```java
import java.util.HashMap;
import java.util.Map;

public class MapDemo {
    public static void main(String[] args) {
        String text = "rag agent rag llm agent rag";
        Map<String, Integer> freq = new HashMap<>();
        for (String w : text.split(" ")) {
            freq.put(w, freq.getOrDefault(w, 0) + 1);
        }
        System.out.println("词频: " + freq);
        System.out.println("rag 出现: " + freq.get("rag"));
        System.out.println("不存在: " + freq.get("xxx"));
        for (Map.Entry<String, Integer> e : freq.entrySet()) {
            System.out.println(e.getKey() + " -> " + e.getValue());
        }
    }
}
```

```bash
javac MapDemo.java && java MapDemo
```

应该看到：`词频: {agent=2, rag=3, llm=1}（顺序不保证）`

**Python**（存为 `map_demo.py`）

```python
text = "rag agent rag llm agent rag"
freq = {}
for w in text.split():
    freq[w] = freq.get(w, 0) + 1
print("词频:", freq)
print("rag 出现:", freq["rag"])
print("不存在:", freq.get("xxx"))
for k, v in freq.items():
    print(k, "->", v)
```

```bash
python map_demo.py
```

应该看到：`词频: {'rag': 3, 'agent': 2, 'llm': 1}`

Map<String, Integer> freq = new HashMap<>();

## 三、今天只要记住这 3 句

1. `Map` 存键值对，键唯一，`HashMap` 用哈希定位、查询 O(1)；遍历顺序不保证，需要顺序用 `LinkedHashMap`。
2. `HashMap` 允许一个 null 键（Hashtable 不允许），非线程安全；并发场景用 `ConcurrentHashMap`，别用 `Collections.synchronizedMap`。
3. RAG 的元数据过滤就是 Map：`{"source": "manual.pdf", "page": 12}`，检索时按它筛子集。

> 今天最容易踩的坑：`HashMap` 的 key 用可变对象（如被修改的 List），改完后 hash 变了，就再也查不到。
