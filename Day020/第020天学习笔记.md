### 任务 1｜实现增删改查 + 按成绩排序 + 统计平均分

**Java**（存为 `StudentApp.java`）

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class StudentApp {
    static class Student {
        String name; int score;
        Student(String n, int s) { name = n; score = s; }
        public String toString() { return name + ":" + score; }
    }

    static List<Student> db = new ArrayList<>();

    static void handle(String cmd, Scanner sc) {
        switch (cmd) {
            case "add" -> {
                System.out.print("姓名 分数: ");
                db.add(new Student(sc.next(), sc.nextInt()));
                System.out.println("已添加，共 " + db.size() + " 人");
            }
            case "list" -> db.forEach(System.out::println);
            case "avg" -> System.out.println("平均: " +
                    db.stream().mapToInt(s -> s.score).average().orElse(0));
            default -> System.out.println("未知命令");
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        while (true) {
            System.out.print("命令(add/list/avg/exit): ");
            String cmd = sc.next();
            if (cmd.equals("exit")) break;
            handle(cmd, sc);
        }
        System.out.println("退出，共 " + db.size() + " 条记录");
    }
}
```

```bash
javac StudentApp.java && java StudentApp   # 输入 add 张三 90 / list / exit
```

应该看到：`已添加，共 1 人 / 张三:90 / 退出，共 1 条记录`

**Python**（存为 `student_app.py`）

```python
# 交互式：运行后依次输入 add 张三 90 / list / avg / exit
db = []

def add(args):
    name, score = args[0], int(args[1])
    db.append({"name": name, "score": score})
    print("已添加，共", len(db), "人")

def list_all(_):
    for s in db:
        print(f"{s['name']}:{s['score']}")

def avg(_):
    print("平均:", sum(s["score"] for s in db) / len(db) if db else 0)

cmds = {"add": add, "list": list_all, "avg": avg}

while True:
    line = input("命令(add/list/avg/exit): ").strip()
    if line == "exit":
        break
    parts = line.split()
    cmds.get(parts[0], lambda _: print("未知命令"))(parts[1:])
print("退出，共", len(db), "条记录")
```

```bash
python student_app.py
```

应该看到：`同 Java，交互式`

## 三、今天只要记住这 3 句

1. 把类、集合、循环、输入拼起来就是一个最小可用系统：数据用集合存，行为用类封装，交互用循环 + 分支。
2. 「能跑」和「好改」的区别在于分层：把输入、业务、存储拆开，加一个功能只改一层；全写在一个 main 里，改一处崩三处。
3. 这就是后面 Agent 的雏形：命令分发 = 意图路由，db = 会话状态，校验 = 工具参数校验。今天写的结构，后面会放大十倍重写一遍。
