## 五、概念详解

### Java 线 · 综合：类 + 集合 + 循环 + 输入

#### 1. 用类建模学生

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。
- **今天的最低要求**：能指着 `综合：类 + 集合 + 循环 + 输入` 里的具体一行说清它在干什么。

#### 2. 用 ArrayList 存数据

- **这是接口/注解型知识**：不用背签名。官方文档搜 `ArrayList`，看清它接收什么、返回什么、什么时候不生效。
- **落地**：写一个最小调用（3–5 行）放进 `综合：类 + 集合 + 循环 + 输入` 的练习里，跑通一次。
- **验证**：把参数改错或去掉注解，看报什么错。错误信息就是最好的文档。

#### 3. 用 switch 做菜单

- **是什么**：按值多分支选择，比一长串 if-else 清晰。
- **为什么重要**：适合「枚举/状态码 → 行为」的映射。
- **怎么用 / 坑**：老语法忘记 `break` 会穿透执行下一个分支；Java 14+ 用箭头语法自动不穿透。

#### 4. 输入校验与异常处理

- **是什么**：程序运行中的非正常情况，用 throw 抛出、catch 捕获。
- **为什么重要**：把「正常流程」和「错误处理」分开，避免每行都返回错误码。
- **怎么用 / 坑**：只捕获你能处理的异常；捕获后要么处理要么包装再抛，绝不空 catch。

### Python 线 · 综合：字典 + 列表 + 函数

#### 1. 用 dict 建模学生

- **是什么**：键值对哈希表，平均 O(1) 查找。
- **为什么重要**：缓存、计数、JSON 解析结果、配置映射都靠它；是 Python 里最重要的数据结构。
- **怎么用 / 坑**：`d.get(k, 默认值)` 避免 KeyError；键必须可哈希，list 不能当键。
- **今天的最低要求**：能指着 `综合：字典 + 列表 + 函数` 里的具体一行说清它在干什么。

#### 2. 用 list 存数据

- **是什么**：有序、可变、可重复的序列，底层是动态数组。
- **为什么重要**：绝大多数「一列数据」的场景都用它；按下标访问是 O(1)，中间插入是 O(n)。
- **怎么用 / 坑**：`append/pop/insert/sort`，切片会复制。循环里删除元素要用倒序或列表推导式。

#### 3. 用 while + match 做菜单

- **是什么**：Python 3.10+ 的模式匹配，类似 switch 但更强。
- **为什么重要**：可匹配结构、类型、多值，适合解析固定形状的数据。
- **怎么用 / 坑**：`case {"type": "a", "value": v}:` 能直接解构字典。

#### 4. 函数拆分每个功能

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | 所有逻辑堆在 main 里会导致后面无法测试和复用 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |

> **40 分钟规则**：一个问题卡超过 40 分钟，记进「待解决清单」继续往下走。周日集中处理。零基础最常见的失败不是学不会，是被一个环境问题卡三天。
