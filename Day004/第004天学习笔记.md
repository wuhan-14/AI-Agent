### 任务 1｜两门语言各写成绩等级判断：90/80/70/60/不及格

**Java**（存为 `Grade.java`）

```java
import java.util.Scanner;

public class Grade {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("请输入分数: ");
        if (!sc.hasNextInt()) {
            System.out.println("不是整数，退出");
            return;
        }
        int s = sc.nextInt();
        String level = s >= 90 ? "A" : s >= 80 ? "B" : s >= 70 ? "C" : s >= 60 ? "D" : "不及格";
        System.out.println("等级: " + level);
    }
}
```

```bash
javac Grade.java && java Grade   # 输入 95
```

应该看到：`等级: A`

**Python**（存为 `grade.py`）

```python
# 运行后按提示输入一个分数，例如 85
raw = input("请输入分数: ")
try:
    s = int(raw)
except ValueError:
    print("不是整数，退出")
else:
    level = "A" if s >= 90 else "B" if s >= 80 else "C" if s >= 70 else "D" if s >= 60 else "不及格"
    print("等级:", level)
```

```bash
python grade.py   # 输入 95
```

应该看到：`等级: A`

### 任务 2｜输入非法值时给出提示而不是崩溃

```java
Scanner sc = new Scanner(System.in);
if (!sc.hasNextInt()) {          // 先判断再读，不判断就抛异常
    System.out.println("请输入整数");
    return;
}
int n = sc.nextInt();
```
```python
raw = input("请输入整数: ")
if not raw.lstrip("-").isdigit():
    print("请输入整数")
else:
    n = int(raw)
```
两门语言的思路一致：**先验证，再转换**。差别是 Java 用 `hasNextInt`，Python 只能拿到字符串自己判断。

## 三、今天只要记住这 3 句

1. `Scanner` 是 Java 的键盘录入工具，`nextInt()` 只读数字、不读换行；`input()` 是 Python 的录入，永远返回字符串。
2. `nextInt()` 后再调 `nextLine()` 会读到空串，因为上一次输入的回车还留在缓冲区里；Python 没有这个坑，但 `input()` 拿到的一定是 str，要自己 `int()`。
3. Agent 的入口就是「解析用户输入」：用户可能输入空、超长、带表情的文本，和今天处理非法输入是同一件事。

> 今天最容易踩的坑：Python 混用 Tab 和空格会报 `TabError`，编辑器里把 Tab 设成 4 空格，一次配好。
