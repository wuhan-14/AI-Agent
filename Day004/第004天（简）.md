## 一、Java 线 · Scanner 键盘录入与 if/else

**核心知识点**：

- Scanner 读整数与读整行
- nextInt 后接 nextLine 的换行坑
- if / else if / else 与嵌套
- 条件必须是 boolean，不能写 if(1)

## 二、Python 线 · input 输入与 if/elif/else

**核心知识点**：

- input() 永远返回字符串
- 缩进即语法，统一四个空格
- elif 不是 else if
- 真值判断：空容器、0、None 都为假
