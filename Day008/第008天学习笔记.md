### 任务 1｜两门语言各存 5 个成绩，求总分、平均分、最高分

**Java**（存为 `ArraySum.java`）

```java
import java.util.Arrays;

public class ArraySum {
    public static void main(String[] args) {
        int[] a = {5, 3, 9, 1, 7};
        int sum = 0, max = a[0];
        for (int x : a) {
            sum += x;
            if (x > max) max = x;
        }
        System.out.println("数组: " + Arrays.toString(a));
        System.out.println("和=" + sum + " 最大值=" + max + " 平均=" + (double) sum / a.length);
        int[] b = new int[3];
        System.out.println("动态初始化默认值: " + Arrays.toString(b));
    }
}
```

```bash
javac ArraySum.java && java ArraySum
```

应该看到：`和=25 最大值=9 平均=5.0 / 默认值: [0, 0, 0]`

**Python**（存为 `list_sum.py`）

```python
a = [5, 3, 9, 1, 7]
print("列表:", a)
print("和=", sum(a), "最大值=", max(a), "平均=", sum(a) / len(a))
a.append(11)
print("append 后:", a, "长度", len(a))
```

```bash
python list_sum.py
```

应该看到：`和= 25 最大值= 9 平均= 5.0`

### 任务 2｜把数组反转后输出

```java
int[] a = new int[3];
System.out.println(Arrays.toString(a));   // [0, 0, 0]
System.out.println(a[3]);                 // 越界异常
```
```python
a = [0] * 3
print(a)
print(a[3])        # IndexError
```
Java 的数组越界抛 `ArrayIndexOutOfBoundsException`，Python 抛 `IndexError`；两者都会中断程序，所以下标计算必须用 `length`，不要写死数字。

**加练（有时间再做）**：

1. 把 `int[] a` 改成 `double[] a`，看平均值的除法还需不需要强转
2. 在 Python 版里 `a[10]`，观察 `IndexError` 的提示
3. Java 里用 `Arrays.copyOf(a, 10)` 扩容，打印新数组看补了什么

> 改代码比抄代码有用：抄只证明你会复制，改才证明你知道每一行控制什么。

## 三、今天只要记住这 3 句

1. 数组是定长、同类型的连续内存；创建时长度就固定，越界访问会抛 `ArrayIndexOutOfBoundsException`。
2. 静态初始化 `int[] a = {1,2,3}` 直接给值，动态初始化 `new int[3]` 只给长度、元素是默认值（int 为 0）；`length` 是属性不是方法，没有括号。
3. RAG 里的向量就是 `float[]`：一次 embedding 返回 1024 维数组，存库、算相似度都在这个结构上操作。

> 今天最容易踩的坑：Java 数组的 `length` 没有括号，`a.length()` 编译不过；字符串的 `length()` 才有括号，两者别混。
