## 五、概念详解

### Java 线 · 值传递、可变参数

#### 1. Java 只有值传递：基本类型传副本、对象传引用副本

- **是什么**：Java 的 8 种内置类型：byte/short/int/long/float/double/char/boolean。
- **为什么重要**：它们不是对象、没有方法、存在栈上，所以快；但集合里装不下。
- **怎么用 / 坑**：需要放进 List/Map 时用包装类，注意拆箱空指针。
- **今天的最低要求**：能指着 `值传递、可变参数` 里的具体一行说清它在干什么。

#### 2. 可变参数 String... args

- **是什么**：`String... args` 允许传任意个同类型参数，本质是数组。
- **为什么重要**：写工具方法时省去手动建数组。
- **怎么用 / 坑**：必须是最后一个参数；传 null 会有歧义。

#### 3. 方法内修改对象内容会影响外部

- **是什么**：类里的函数，把一段逻辑命名后复用。
- **为什么重要**：拆方法的标准：这段代码能用一句话说清在干什么。
- **怎么用 / 坑**：一个方法只做一件事；参数超过 4 个考虑封装成对象。

#### 4. 递归的基线条件

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

### Python 线 · 参数进阶：*args、**kwargs、解包

#### 1. *args 收集位置参数、**kwargs 收集关键字参数

- **是什么**：调用时用 `f(name="x")` 指定参数名，顺序随意。
- **为什么重要**：参数多时可读性大幅提升，也避免传错位置。
- **怎么用 / 坑**：位置参数必须在关键字参数之前。
- **今天的最低要求**：能指着 `参数进阶：*args、**kwargs、解包` 里的具体一行说清它在干什么。

#### 2. * 与 ** 在调用时解包

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「写一个方法交换两个 int，验证外部没变」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。

#### 3. 可变对象作为参数会被修改

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

#### 4. 递归与递归深度限制

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | 以为「Java 对象是引用传递」是最常见的误解 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |
