### 任务 1｜用 switch 重写成绩等级判断

**Java**（存为 `Menu.java`）

```java
public class Menu {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            String level = switch (i) {
                case 1 -> "A";
                case 2 -> "B";
                default -> "C";
            };
            System.out.println(i + " -> " + level);
        }
        int n = 3;
        while (n > 0) {
            System.out.println("倒计时 " + n);
            n--;
        }
        System.out.println("exit");
    }
}
```

```bash
javac Menu.java && java Menu
```

应该看到：`1 -> A / 2 -> B / 3 -> C / 倒计时 3 / 2 / 1 / exit`

**Python**（存为 `menu.py`）

```python
for i in range(1, 4):
    match i:
        case 1:
            level = "A"
        case 2:
            level = "B"
        case _:
            level = "C"
    print(i, "->", level)

n = 3
while n > 0:
    print("倒计时", n)
    n -= 1
print("exit")
```

```bash
python menu.py
```

应该看到：`1 -> A / 2 -> B / 3 -> C / 倒计时 3 / 2 / 1 / exit`

### 任务 2｜写一个「输入 exit 才退出」的菜单循环

```java
Scanner sc = new Scanner(System.in);
while (true) {
    System.out.print("命令(1-3, 0 退出): ");
    int cmd = sc.nextInt();
    if (cmd == 0) break;
    switch (cmd) {
        case 1 -> System.out.println("查询");
        case 2 -> System.out.println("新增");
        case 3 -> System.out.println("删除");
        default -> System.out.println("无效命令");
    }
}
```
```python
while True:
    cmd = input("命令(1-3, 0 退出): ").strip()
    if cmd == "0":
        break
    match cmd:
        case "1": print("查询")
        case "2": print("新增")
        case "3": print("删除")
        case _: print("无效命令")
```
菜单循环是所有控制台程序的骨架，后面学生管理、Agent 的交互入口都是它的变体。

**加练（有时间再做）**：

1. 把箭头 switch 改成老式 `case 1:` 并故意不写 `break`，看穿透
2. 给菜单加一个 `case 0 -> "退出"` 并用 `break` 结束循环
3. Python 的 `match` 加一个 `case 0:`，确认 `_` 必须放最后

> 改代码比抄代码有用：抄只证明你会复制，改才证明你知道每一行控制什么。

## 三、今天只要记住这 3 句

1. `switch` 按值跳转，比一串 `if-else` 更清楚；老式写法忘写 `break` 会「穿透」到下一个分支，Java 14+ 的箭头语法和 Python 的 `match/case` 都没有这个问题。
2. `while` 先判断后执行，可能一次都不执行；`do-while` 至少执行一次。`break` 跳出整个循环，`continue` 只跳过本次。
3. Agent 的「意图路由」就是这个结构：判断用户要查数据、查文档还是闲聊，再分派给不同工具。写错一个分支，后面全错。

> 今天最容易踩的坑：Java 老式 switch 的 `case 1:` 后忘记 `break`，会继续执行 case 2 的代码，且不报错。
