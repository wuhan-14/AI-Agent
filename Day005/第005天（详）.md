## 五、概念详解

### Java 线 · switch 与循环入门

#### 1. switch 的穿透与 break

- **是什么**：按值多分支选择，比一长串 if-else 清晰。
- **为什么重要**：适合「枚举/状态码 → 行为」的映射。
- **怎么用 / 坑**：老语法忘记 `break` 会穿透执行下一个分支；Java 14+ 用箭头语法自动不穿透。
- **今天的最低要求**：能指着 `switch 与循环入门` 里的具体一行说清它在干什么。

#### 2. Java 14+ 箭头语法与 yield

- **这是接口/注解型知识**：不用背签名。官方文档搜 `Java`，看清它接收什么、返回什么、什么时候不生效。
- **落地**：写一个最小调用（3–5 行）放进 `switch 与循环入门` 的练习里，跑通一次。
- **验证**：把参数改错或去掉注解，看报什么错。错误信息就是最好的文档。

#### 3. while 与 do-while 的区别

- **是什么**：先执行一次再判断条件，至少执行一次。
- **为什么重要**：菜单循环、重试逻辑适合它。
- **怎么用 / 坑**：注意条件后面有分号：`while (x < 3);`

#### 4. break / continue 的作用

- **是什么**：跳过本次循环剩余部分，进入下一次。
- **为什么重要**：过滤不满足条件的元素时比嵌套 if 清晰。
- **怎么用 / 坑**：注意别在 while 里忘记更新循环变量，会死循环。

### Python 线 · while 循环与 match

#### 1. while 的条件与退出

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「用 switch 重写成绩等级判断」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。
- **今天的最低要求**：能指着 `while 循环与 match` 里的具体一行说清它在干什么。

#### 2. break/continue

- **是什么**：跳过本次循环剩余部分，进入下一次。
- **为什么重要**：过滤不满足条件的元素时比嵌套 if 清晰。
- **怎么用 / 坑**：注意别在 while 里忘记更新循环变量，会死循环。

#### 3. Python 3.10 match/case 的基本写法

- **是什么**：Python 3.10+ 的模式匹配，类似 switch 但更强。
- **为什么重要**：可匹配结构、类型、多值，适合解析固定形状的数据。
- **怎么用 / 坑**：`case {"type": "a", "value": v}:` 能直接解构字典。

#### 4. 循环变量必须手动更新

- **是什么**：一个「名字」绑定到内存里的某个值，改名不改变值本身。
- **为什么重要**：程序所有状态都靠它保存；理解「绑定」而不是「盒子」，才不会在赋值和传参上犯迷糊。
- **怎么用 / 坑**：Java 必须先声明类型，Python 直接赋值。重新赋值只是让名字指向新对象，旧对象没人引用就被回收。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | 老式 switch 忘记 break 会继续执行下一个分支 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |

> **40 分钟规则**：一个问题卡超过 40 分钟，记进「待解决清单」继续往下走。周日集中处理。零基础最常见的失败不是学不会，是被一个环境问题卡三天。
