## 五、概念详解

### Java 线 · Random、循环综合练习

#### 1. Random 生成指定范围随机数

- **这是接口/注解型知识**：不用背签名。官方文档搜 `Random`，看清它接收什么、返回什么、什么时候不生效。
- **落地**：写一个最小调用（3–5 行）放进 `Random、循环综合练习` 的练习里，跑通一次。
- **验证**：把参数改错或去掉注解，看报什么错。错误信息就是最好的文档。
- **今天的最低要求**：能指着 `Random、循环综合练习` 里的具体一行说清它在干什么。

#### 2. while(true) 与退出条件

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「写猜数字游戏：1-100，最多 7 次，提示大了小了」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。

#### 3. 循环里的输入校验

- **是什么**：用注解声明字段约束，由框架在进入业务前拦截非法输入。
- **为什么重要**：把「参数合法性」从业务代码里抽出来，避免满屏 if。
- **怎么用 / 坑**：`@NotBlank/@Size/@Min/@Valid`；嵌套对象要加 `@Valid`。

### Python 线 · random 模块与循环综合

#### 1. random.randint / choice / shuffle

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。
- **今天的最低要求**：把这组清单里的每一项都能在自己机器上找到对应位置。

#### 2. while True + break 的菜单模式

- **是什么**：立即跳出当前循环。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | Random 的边界是左闭右开还是双闭要查文档 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |

> **40 分钟规则**：一个问题卡超过 40 分钟，记进「待解决清单」继续往下走。周日集中处理。零基础最常见的失败不是学不会，是被一个环境问题卡三天。
