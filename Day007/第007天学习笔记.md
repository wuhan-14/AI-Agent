### 任务 1｜写猜数字游戏：1-100，最多 7 次，提示大了小了

**Java**（存为 `Guess.java`）

```java
import java.util.Random;

public class Guess {
    public static void main(String[] args) {
        Random r = new Random(42);
        int target = r.nextInt(100) + 1;
        int low = 1, high = 100, count = 0;
        while (low <= high) {
            count++;
            int guess = (low + high) / 2;
            if (guess == target) break;
            if (guess < target) low = guess + 1;
            else high = guess - 1;
        }
        System.out.println("目标=" + target + " 猜了 " + count + " 次");
    }
}
```

```bash
javac Guess.java && java Guess
```

应该看到：`目标=31 猜了 4 次（固定种子 42 时结果稳定）`

**Python**（存为 `guess.py`）

```python
import random

random.seed(42)
target = random.randint(1, 100)
low, high, count = 1, 100, 0
while low <= high:
    count += 1
    guess = (low + high) // 2
    if guess == target:
        break
    if guess < target:
        low = guess + 1
    else:
        high = guess - 1
print("目标=", target, "猜了", count, "次")
```

```bash
python guess.py
```

应该看到：`目标= 82 猜了 6 次`

### 任务 2｜统计 100 次随机数中每个数字出现的次数

```python
import random
random.seed(42)
counts = {i: 0 for i in range(1, 7)}
for _ in range(6000):
    counts[random.randint(1, 6)] += 1
print(counts)
```
```java
Random r = new Random(42);
int[] cnt = new int[7];
for (int i = 0; i < 6000; i++) cnt[r.nextInt(6) + 1]++;
System.out.println(Arrays.toString(cnt));
```
每个点数应该接近 1000 次。偏离太多说明你的范围写错了（比如 `nextInt(6)` 少了 +1，1 永远出不来）。

## 三、今天只要记住这 3 句

1. 随机数由「种子 + 算法」生成，同样的种子必然得到同样的序列，所以测试时要固定种子，否则 bug 复现不了。
2. `Random.nextInt(bound)` 生成 `[0, bound)` 的整数，要 1–100 得写 `nextInt(100) + 1`；Python 的 `random.randint(a, b)` 是闭区间，两边都取得到。
3. Agent 的采样温度（temperature）本质也是随机；做评测时必须 `temperature=0` 或固定种子，否则同一题两次跑出不同分数。

> 今天最容易踩的坑：`nextInt(100)` 永远取不到 100，想模拟 1–100 必须 `+1`，这是最常见的 off-by-one。
