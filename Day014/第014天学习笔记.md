### 任务 1｜写一个标准 JavaBean（User：id/name/age）

**Java**（存为 `BeanDemo.java`）

```java
import java.util.ArrayList;
import java.util.List;

public class BeanDemo {
    static class User {
        private String name;
        private int age;

        public User() {}
        public User(String name, int age) {
            this.name = name;
            this.age = age;
        }
        public String getName() { return name; }
        public void setName(String name) { this.name = name; }
        public int getAge() { return age; }
        public void setAge(int age) { this.age = age; }
        public String toString() { return name + "(" + age + ")"; }
    }

    public static void main(String[] args) {
        List<User> users = new ArrayList<>();
        users.add(new User("张三", 20));
        users.add(new User("李四", 21));
        System.out.println(users);
        System.out.println("人数: " + users.size());
    }
}
```

```bash
javac BeanDemo.java && java BeanDemo
```

应该看到：`[张三(20), 李四(21)] / 人数: 2`

**Python**（存为 `obj_list.py`）

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"{self.name}({self.age})"

users = [User("张三", 20), User("李四", 21)]
print(users)
print("人数:", len(users))
print("按年龄排序:", sorted(users, key=lambda u: u.age))
```

```bash
python obj_list.py
```

应该看到：`[张三(20), 李四(21)] / 人数: 2`

### 任务 2｜创建 5 个 User 放进数组，按年龄排序输出

```java
List<User> users = new ArrayList<>();
users.add(new User("张三", 20));
users.sort((x, y) -> x.getAge() - y.getAge());
```
```python
users = [User("张三", 20), User("李四", 21)]
users.sort(key=lambda u: u.age)
```
对象列表的排序差别就在「比较依据」：Java 传 Comparator，Python 传 key 函数。`key` 返回什么就按什么排，比写比较器简单。

## 三、今天只要记住这 3 句

1. 构造方法在 `new` 时执行，用来把对象初始化到合法状态；不写时 Java 给一个无参默认构造，一旦自己写了带参构造，默认的就没有了。
2. JavaBean 规范是「无参构造 + private 属性 + getter/setter」，框架（Spring、MyBatis）靠它反射创建对象，破坏规范会导致注入失败。
3. RAG 的 Document、Chunk、检索结果都用这种「数据类」承载；字段设计错了，序列化成 JSON 给前端时就得反复改。

> 今天最容易踩的坑：写了带参构造却不写无参构造，是 Spring 项目启动失败的经典原因，且报错信息很绕。
