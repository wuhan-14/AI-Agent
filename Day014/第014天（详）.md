## 五、概念详解

### Java 线 · 构造方法、JavaBean 标准写法

#### 1. 构造方法的作用与重载

- **是什么**：类里的函数，把一段逻辑命名后复用。
- **为什么重要**：拆方法的标准：这段代码能用一句话说清在干什么。
- **怎么用 / 坑**：一个方法只做一件事；参数超过 4 个考虑封装成对象。
- **今天的最低要求**：能指着 `构造方法、JavaBean 标准写法` 里的具体一行说清它在干什么。

#### 2. this(...) 调用同类构造器

- **是什么**：指向当前对象的引用。
- **为什么重要**：区分同名字段与参数，或在构造器间互相调用。
- **怎么用 / 坑**：`this.name = name`；Python 对应 `self.name = name`。

#### 3. JavaBean 规范：无参构造 + getter/setter

- **是什么**：由 Spring 容器管理的对象，默认单例。
- **为什么重要**：单例意味着**不要放可变状态**，否则并发下会串数据。
- **怎么用 / 坑**：`@Component/@Service/@Repository` 或 `@Bean` 方法声明；需要多例用 `@Scope`。

#### 4. 对象数组与遍历

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「写一个标准 JavaBean（User：id/name/age）」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。

### Python 线 · 对象列表与字典建模

#### 1. 用列表存对象

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。
- **今天的最低要求**：能指着 `对象列表与字典建模` 里的具体一行说清它在干什么。

#### 2. 用字典表示一条记录

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

#### 3. dataclass 简化数据类

- **是什么**：用装饰器自动生成 `__init__`、`__repr__`、`__eq__` 的类。
- **为什么重要**：写数据载体时省掉大量样板，比手写类更不容易错。
- **怎么用 / 坑**：`@dataclass class User: id: int; name: str`；要不可变加 `frozen=True`。

#### 4. 对象与 JSON 的对应关系

- **是什么**：轻量级数据交换格式，键值对 + 数组。
- **为什么重要**：前后端、服务间通信的通用语言。
- **怎么用 / 坑**：字符串必须双引号、不能有注释、不能有尾逗号。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | 只写带参构造会让框架无法实例化（Spring/Jackson 常需要无参构造） | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |
