## 一、Java 线 · 构造方法、JavaBean 标准写法

**核心知识点**：

- 构造方法的作用与重载

- JavaBean 规范：无参构造 + getter/setter

## 二、Python 线 · 对象列表与字典建模

**核心知识点**：

- 用列表存对象
- 用字典表示一条记录

- 对象与 JSON 的对应关系

## 三、动手任务

1. 写一个标准 JavaBean（User：id/name/age）
2. 创建 5 个 User 放进数组，按年龄排序输出
3. Python 用 dataclass 写同样的类并用 list 存 5 个

## 四、验收标准

- [ ] JavaBean 有无参构造，能被框架正常创建
- [ ] 排序结果按年龄升序

## 五、常见坑

只写带参构造会让框架无法实例化（Spring/Jackson 常需要无参构造）；sort 比较对象要实现 Comparable 或传 Comparator。
