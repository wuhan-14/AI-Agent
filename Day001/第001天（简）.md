## 一、Java 线 · JDK 安装、IDEA、第一个 Java 程序

**核心知识点**：

- JDK / JRE / JVM 三者关系
- javac 编译与 java 运行两条命令
- main 方法各部分的含义
- IDEA 新建项目的目录结构

**参考代码**（先手敲，再改 3 处）：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
```

## 二、Python 线 · Python 安装、VS Code、第一个脚本

**核心知识点**：

- 解释器与脚本文件的关系
- python 与 python3 指向哪个版本
- pip 与 venv 的作用
- VS Code 选择解释器

**参考代码**：

```python
print("Hello, Python")
```

- [ ] java -version、javac -version、python -V 三条命令都有输出
