## 五、概念详解

### Java 线 · JDK 安装、IDEA、第一个 Java 程序

#### 1. JDK / JRE / JVM 三者关系

- **是什么**：Java 开发工具包，包含编译器 javac、运行时 JVM 和标准库。
- **为什么重要**：装 JDK 就同时有了 JRE 和 JVM；只装 JRE 能运行但不能编译。
- **怎么用 / 坑**：`java -version` 和 `javac -version` 都要能输出版本，且版本一致。
- **今天的最低要求**：能指着 `JDK 安装、IDEA、第一个 Java 程序` 里的具体一行说清它在干什么。

#### 2. javac 编译与 java 运行两条命令

- **是什么**：Java 编译器，把 .java 源文件编译成 .class 字节码。
- **为什么重要**：理解「先编译再运行」是理解 Java 的第一步，也是和 Python 最大的区别。
- **怎么用 / 坑**：`javac Hello.java` 生成 Hello.class，再 `java Hello` 运行（不带 .class 后缀）。

#### 3. main 方法各部分的含义

- **是什么**：类里的函数，把一段逻辑命名后复用。
- **为什么重要**：拆方法的标准：这段代码能用一句话说清在干什么。
- **怎么用 / 坑**：一个方法只做一件事；参数超过 4 个考虑封装成对象。

#### 4. IDEA 新建项目的目录结构

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

### Python 线 · Python 安装、VS Code、第一个脚本

#### 1. 解释器与脚本文件的关系

- **是什么**：逐行读取并执行代码的程序，Python 靠它运行。
- **为什么重要**：没有编译产物，改完直接跑，所以开发快；代价是运行期才发现类型错误。
- **怎么用 / 坑**：`python script.py` 启动解释器执行脚本；交互式输入 `python` 进入 REPL。
- **今天的最低要求**：能指着 `Python 安装、VS Code、第一个脚本` 里的具体一行说清它在干什么。

#### 2. python 与 python3 指向哪个版本

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「两门语言各写一个 HelloWorld，命令行和 IDE 各跑一次」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。

#### 3. pip 与 venv 的作用

- **是什么**：Python 的虚拟环境，给每个项目独立的依赖目录。
- **为什么重要**：不同项目依赖版本冲突时，虚拟环境是唯一干净解法。
- **怎么用 / 坑**：`python -m venv .venv` 创建，激活后 `pip install`。别把包装进系统 Python。

#### 4. VS Code 选择解释器

- **是什么**：逐行读取并执行代码的程序，Python 靠它运行。
- **为什么重要**：没有编译产物，改完直接跑，所以开发快；代价是运行期才发现类型错误。
- **怎么用 / 坑**：`python script.py` 启动解释器执行脚本；交互式输入 `python` 进入 REPL。

## 六、代码精读

### JAVA 版

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
```

**读法**：先整体看一遍结构，再逐行问三个问题——这行输入什么、改了什么状态、输出到哪。

**改三处**（必须做，否则等于抄）：
1. 换一个输入值，观察输出怎么变。
2. 删掉一行，看报错信息，理解这行的作用。
3. 加一个小功能（多一个字段/多一层判断），不看示例自己写。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | PATH 没配好会出现「命令找不到」 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |

> **40 分钟规则**：一个问题卡超过 40 分钟，记进「待解决清单」继续往下走。周日集中处理。零基础最常见的失败不是学不会，是被一个环境问题卡三天。
