### 任务 1｜把 Student 的年龄改成 private，用 setter 限制 0-150

**Java**（存为 `Account.java`）

```java
public class Account {
    private double balance;

    public double getBalance() {
        return balance;
    }

    public void deposit(double amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("金额必须大于 0");
        }
        balance += amount;
    }

    public static void main(String[] args) {
        Account a = new Account();
        a.deposit(100);
        System.out.println("余额: " + a.getBalance());
        try {
            a.deposit(-50);
        } catch (IllegalArgumentException e) {
            System.out.println("被拦住: " + e.getMessage());
        }
    }
}
```

```bash
javac Account.java && java Account
```

应该看到：`余额: 100.0 / 被拦住: 金额必须大于 0`

**Python**（存为 `account.py`）

```python
class Account:
    def __init__(self):
        self._balance = 0.0

    @property
    def balance(self):
        return self._balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("金额必须大于 0")
        self._balance += amount

a = Account()
a.deposit(100)
print("余额:", a.balance)
a._balance = -999
print("直接改私有属性:", a.balance)
```

```bash
python account.py
```

应该看到：`余额: 100.0 / 直接改私有属性: -999`

### 任务 2｜构造方法重载：无参、全参两个版本

```java
public void setScore(int score) {
    if (score < 0 || score > 100) {
        throw new IllegalArgumentException("分数必须在 0-100");
    }
    this.score = score;
}
```
```python
@score.setter
def score(self, value):
    if not 0 <= value <= 100:
        raise ValueError("分数必须在 0-100")
    self._score = value
```
把校验写在 setter 里，所有赋值入口就都被管住了；写在调用方，只要有人忘了判断就漏。

## 三、今天只要记住这 3 句

1. 封装是把属性设为 `private`、只通过方法暴露读写，目的是让「谁能改、改成什么」由类自己控制，而不是靠调用方自觉。
2. `private` 是类可见，`this` 指当前对象，用来区分成员变量和同名参数；getter/setter 不是形式主义，校验逻辑就写在这里。
3. Agent 的工具参数校验就是同一件事：在入口拦住非法值，比在链路中间报错好排查一百倍。

> 今天最容易踩的坑：Python 的 `__balance` 会被改名成 `_Account__balance`，外部仍能访问；它只防手滑，不防恶意。
