## 五、概念详解

### Java 线 · 封装与 this

#### 1. private 的作用与封装的意义

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「把 Student 的年龄改成 private，用 setter 限制 0-150」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。
- **今天的最低要求**：能指着 `封装与 this` 里的具体一行说清它在干什么。

#### 2. this 指向当前对象

- **是什么**：指向当前对象的引用。
- **为什么重要**：区分同名字段与参数，或在构造器间互相调用。
- **怎么用 / 坑**：`this.name = name`；Python 对应 `self.name = name`。

#### 3. getter/setter 与字段校验

- **是什么**：不重复元素的无序集合，底层哈希表。
- **为什么重要**：去重和「是否存在」判断的最快方案，比 list 的 `in` 快一个量级。
- **怎么用 / 坑**：`a & b` 交集、`a | b` 并集。空集合写 `set()`，`{}` 是空字典。

#### 4. 构造方法重载

- **是什么**：类里的函数，把一段逻辑命名后复用。
- **为什么重要**：拆方法的标准：这段代码能用一句话说清在干什么。
- **怎么用 / 坑**：一个方法只做一件事；参数超过 4 个考虑封装成对象。

### Python 线 · 封装与属性控制

#### 1. _ 与 __ 的命名约定

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「把 Student 的年龄改成 private，用 setter 限制 0-150」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。
- **今天的最低要求**：能指着 `封装与属性控制` 里的具体一行说清它在干什么。

#### 2. @property 把方法当属性用

- **是什么**：类里的函数，把一段逻辑命名后复用。
- **为什么重要**：拆方法的标准：这段代码能用一句话说清在干什么。
- **怎么用 / 坑**：一个方法只做一件事；参数超过 4 个考虑封装成对象。

#### 3. setter 中做校验

- **是什么**：不重复元素的无序集合，底层哈希表。
- **为什么重要**：去重和「是否存在」判断的最快方案，比 list 的 `in` 快一个量级。
- **怎么用 / 坑**：`a & b` 交集、`a | b` 并集。空集合写 `set()`，`{}` 是空字典。

#### 4. 私有属性并非绝对不可访问

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | setter 里忘记 this 会导致自己赋值给自己，字段永远是默认值 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |
