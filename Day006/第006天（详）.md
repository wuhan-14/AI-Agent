## 五、概念详解

### Java 线 · for 循环与嵌套

#### 1. 传统 for 的三段式执行顺序

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。
- **今天的最低要求**：能指着 `for 循环与嵌套` 里的具体一行说清它在干什么。

#### 2. 增强 for 遍历数组与集合

- **是什么**：`for (String s : list)` 直接遍历元素，不拿下标。
- **为什么重要**：代码更短、不会越界，是遍历集合的首选。
- **怎么用 / 坑**：遍历时不能增删集合元素，否则 ConcurrentModificationException。

#### 3. 嵌套循环与循环变量作用域

- **是什么**：变量能被访问的代码范围，Java 按块，Python 按函数加 LEGB 规则。
- **为什么重要**：作用域混乱是「明明赋值了却还是旧值」的根源，尤其是闭包和循环变量。
- **怎么用 / 坑**：Python 函数内赋值会创建局部变量，要改全局得 `global`；列表 append 不需要。

#### 4. 带标签的 break

- **是什么**：立即跳出当前循环。
- **为什么重要**：配合「找到就停」的逻辑，避免无谓遍历。
- **怎么用 / 坑**：只跳一层；多层要标签或抽方法。

### Python 线 · for 循环与 range

#### 1. range(start, stop, step) 右开区间

- **是什么**：生成整数序列，`range(start, stop, step)`，右开区间。
- **为什么重要**：`range(5)` 是 0–4，不含 5，这是新手最高频的差一错误来源。
- **怎么用 / 坑**：`range(10, 0, -1)` 倒序；它返回惰性对象，不是列表。
- **今天的最低要求**：能指着 `for 循环与 range` 里的具体一行说清它在干什么。

#### 2. enumerate 同时拿下标和值

- **是什么**：固定数量的常量集合，类型安全。
- **为什么重要**：状态机、角色、类型字段用它，避免魔法字符串和非法值。
- **怎么用 / 坑**：Java enum 可以带字段和方法；Python 用 `Enum`。数据库里存名称而不是序号。

#### 3. 嵌套循环打印图形

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

#### 4. for-else 的语义

- **是什么**：Python 的 for 循环正常结束才执行 else，break 跳过。
- **为什么重要**：用于「找没找到」的判断，省掉一个标志变量。
- **怎么用 / 坑**：`for x in xs: if ok: break` / `else: print("没找到")`。

## 六、代码精读

### JAVA 版

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i * j) + "\t");
    }
    System.out.println();
}
```

**读法**：先整体看一遍结构，再逐行问三个问题——这行输入什么、改了什么状态、输出到哪。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | 循环变量在循环外被修改、条件写错导致死循环，是新手最常见的两个卡点。 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |
