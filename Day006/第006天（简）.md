## 一、Java 线 · for 循环与嵌套

**核心知识点**：

- 传统 for 的三段式执行顺序
- 增强 for 遍历数组与集合
- 嵌套循环与循环变量作用域
- 带标签的 break

**参考代码**（先手敲，再改 3 处）：

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i * j) + "\t");
    }
    System.out.println();
}
```

## 二、Python 线 · for 循环与 range

**核心知识点**：

- range(start, stop, step) 右开区间
- enumerate 同时拿下标和值
- 嵌套循环打印图形
- for-else 的语义

**参考代码**：

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}*{i}={i*j}", end="\t")
    print()
```
