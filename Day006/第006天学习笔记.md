## 一、动手：3 个任务的参考答案

### 任务 1｜打印九九乘法表

**Java**（存为 `Table.java`）

```java
public class Table {
    public static void main(String[] args) {
        for (int i = 1; i <= 9; i++) {
            StringBuilder line = new StringBuilder();
            for (int j = 1; j <= i; j++) {
                line.append(j).append("x").append(i).append("=").append(i * j).append("\t");
            }
            System.out.println(line);
        }
    }
}
```

```bash
javac Table.java && java Table
```

应该看到：`1x1=1 / 1x2=2 2x2=4 / …`

**Python**（存为 `table.py`）

```python
for i in range(1, 10):
    line = "".join(f"{j}x{i}={i*j}\t" for j in range(1, i + 1))
    print(line)
```

```bash
python table.py
```

应该看到：`同上，9 行乘法表`

### 任务 2｜用嵌套循环打印一个菱形

```java
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5 - i; j++) System.out.print(" ");
    for (int j = 1; j <= 2 * i - 1; j++) System.out.print("*");
    System.out.println();
}
```
```python
for i in range(1, 6):
    print(" " * (5 - i) + "*" * (2 * i - 1))
```
同一个图形，Java 用两个内层循环控制空格和星号，Python 直接用字符串乘法。想清楚「每行打印几个、前面空几个」，嵌套循环就不难了。

2. 加一个计数器，统计一共打印了多少个算式
3. Python 版改成两层普通 for + `print(end="")`，对比 join 写法

> 改代码比抄代码有用：抄只证明你会复制，改才证明你知道每一行控制什么。

## 三、今天只要记住这 3 句

1. `for` 适合「次数已知」的循环：初始化、条件、更新三件事写在一行，执行顺序是「初始化 → 判断 → 循环体 → 更新 → 再判断」。
2. 普通 for 能拿到下标，增强 for（`for (int x : arr)`）只能读元素、改不了原数组；需要下标或要修改元素时必须用普通 for。
3. 批量处理文档时就是双层循环：外层遍历文件，内层遍历切分出的段落；嵌套写错会导致重复入库或漏入库。

> 今天最容易踩的坑：Python 的 `range(1, 10)` 是 1–9，不含 10；写成 `range(1, 9)` 会少一行，且不报错。
