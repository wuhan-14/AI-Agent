## 五、概念详解

### Java 线 · 变量、基本类型与类型转换

#### 1. byte/short/int/long/float/double/char/boolean 与取值范围

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。
- **今天的最低要求**：把这组清单里的每一项都能在自己机器上找到对应位置。

#### 2. 变量声明、初始化与命名规范

- **是什么**：Java：类名 PascalCase、变量与方法 camelCase、常量全大写下划线；Python：变量函数 snake_case、类 PascalCase。
- **为什么重要**：统一命名不是为了好看，是让别人（和三个月后的你）能一眼看懂。
- **怎么用 / 坑**：名字要能读出用途：`retryCount` 好过 `rc`；不要用拼音。

#### 3. 自动类型提升与强制转换

- **是什么**：用 `(int)` 把宽类型窄化，可能丢精度或溢出。
- **为什么重要**：`(int) 3.9` 得 3（直接截断，不是四舍五入）。
- **怎么用 / 坑**：转换前判断范围；浮点转整建议 `Math.round()`。

#### 4. int 与 Integer 的区别（装箱）

- **是什么**：32 位整数，范围约 ±21 亿。
- **为什么重要**：最常用的整数类型；金额、ID 超范围要换 long。
- **怎么用 / 坑**：两个 int 相除结果还是 int，`5/2` 得 2 不是 2.5。

### Python 线 · 变量、动态类型与 None

#### 1. 变量是标签不是盒子，重新赋值只是换指向

- **是什么**：一个「名字」绑定到内存里的某个值，改名不改变值本身。
- **为什么重要**：程序所有状态都靠它保存；理解「绑定」而不是「盒子」，才不会在赋值和传参上犯迷糊。
- **怎么用 / 坑**：Java 必须先声明类型，Python 直接赋值。重新赋值只是让名字指向新对象，旧对象没人引用就被回收。
- **今天的最低要求**：能指着 `变量、动态类型与 None` 里的具体一行说清它在干什么。

#### 2. type() 查看类型，isinstance() 判断

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

#### 3. int/float/str/bool/None 五种常用类型

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。

#### 4. snake_case 命名与 None 的语义

- **是什么**：Python 的「空值」，表示没有值。
- **为什么重要**：函数没有 return 就返回 None；它是对象，有自己的类型 NoneType。
- **怎么用 / 坑**：`None == 0` 是 False；判断用 `is None`，不要用 `==`。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |

| 程序起不来 / 报错 | Java 局部变量必须先赋值才能用 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |

| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |
