### 任务 1｜两种语言各定义 5 个不同类型的变量并打印类型

**Java**（存为 `Types.java`）

```java
public class Types {
    public static void main(String[] args) {
        int i = 2_000_000_000;
        long l = 9_000_000_000L;
        double d = 3.14;
        char c = 'A';
        boolean ok = true;
        int overflow = i + i;
        System.out.println("int=" + i + " long=" + l + " double=" + d);
        System.out.println("char=" + c + " boolean=" + ok);
        System.out.println("溢出结果: " + overflow);
        Integer boxed = i;
        System.out.println("装箱后类型: " + boxed.getClass().getName());
    }
}
```

```bash
javac Types.java && java Types
```

应该看到：`溢出结果: -294967296`

**Python**（存为 `types.py`）

```python
big = 2_000_000_000 * 2
print("Python 整数没有上限:", big, type(big))

x = None
print("None 的类型:", type(x), "布尔值:", bool(x))
print("isinstance 判断:", isinstance(big, int))
```

```bash
python types.py
```

应该看到：`Python 整数没有上限: 4000000000 <class 'int'>`

### 任务 2｜验证 Java 的整数溢出与 Python 的大整数，解释差异

```java
int i = Integer.MAX_VALUE;
System.out.println(i + 1);      // -2147483648
```
```python
print(2**63)
print(2**63 + 1)                # 两个都正常输出
```
Java 的 `int` 是 32 位，超出就回绕且不报错；Python 的 `int` 是任意精度，只要内存够就一直加。这不是「Python 更强」，而是两者对整数的定义不同：Java 贴硬件，Python 贴数学。

2. 把 `Integer boxed = i` 改成 `Integer boxed = null`，再调用 `boxed + 1`，观察空指针
3. 在 Python 里对 `big` 做 `big / 2`，确认结果变成 float

### 任务 3｜验证 5/2 在两门语言中的结果差异

```java
System.out.println(5 / 2);      // 2
System.out.println(5 / 2.0);    // 2.5
```
```python
print(5 / 2, 5 // 2)            # 2.5 2
```
记一句：**Java 的 `/` 看操作数类型，Python 的 `/` 永远是真除法**。算平均分、算相似度、算成本时，这一条会反复出现。

## 三、今天只要记住这 3 句

1. Java 有 8 种基本类型，大小固定、有取值范围；超出范围会静默回绕，不报错。
2. 基本类型（int）存值、放在栈上，包装类型（Integer）是对象、可以为 null；集合里只能放包装类型，比较时 `==` 比的是引用地址，要用 `equals`。
3. RAG 里所有计数（token 数、条数、耗时）都用整数；Java 侧如果用了 int 存毫秒时间戳会溢出，必须用 long——这是线上容易出的事故。

> 今天最容易踩的坑：Java 的 `char` 是 16 位无符号整数，`'A' + 1` 得到 66，不是 'B'，要强转才变字符。
