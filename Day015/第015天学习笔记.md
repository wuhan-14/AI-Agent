### 任务 1｜统计一个字符串里每个字符出现的次数

**Java**（存为 `StrDemo.java`）

```java
public class StrDemo {
    public static void main(String[] args) {
        String s = "  Hello, RAG World  ";
        System.out.println("长度: " + s.length());
        System.out.println("去空格: [" + s.trim() + "]");
        System.out.println("含 RAG: " + s.contains("RAG"));
        System.out.println("替换: " + s.replace("World", "Agent").trim());
        System.out.println("切片: " + s.trim().substring(7, 10));
        String[] parts = s.trim().split(", ");
        System.out.println("切分: " + parts[0] + " | " + parts[1]);
        String a = "abc", b = "abc";
        System.out.println("== " + (a == b) + " equals " + a.equals(b));
    }
}
```

```bash
javac StrDemo.java && java StrDemo
```

应该看到：`含 RAG: true / == true equals true（字面量共享常量池）`

**Python**（存为 `str_demo.py`）

```python
s = "  Hello, RAG World  "
print("长度:", len(s))
print("去空格: [%s]" % s.strip())
print("含 RAG:", "RAG" in s)
print("替换:", s.replace("World", "Agent").strip())
print("切片:", s.strip()[7:10])
parts = s.strip().split(", ")
print("切分:", parts[0], "|", parts[1])
print("负索引:", s.strip()[-5:])
```

```bash
python str_demo.py
```

应该看到：`含 RAG: True / 负索引: World`

### 任务 2｜把「姓名:张三;年龄:18」解析成键值对

```java
String s = "a,b,,c";
System.out.println(s.split(",").length);     // 4，中间空串保留
System.out.println(s.split(",", -1).length); // 4
System.out.println("a.b".split(".").length); // 0，因为 . 是正则
System.out.println("a.b".split("\\.").length); // 2
```
```python
print(len("a,b,,c".split(",")))   # 4
print("a.b".split("."))           # ['a', 'b']，Python 不需要转义
```
Java 的 `split` 吃正则、Python 的 `split` 吃普通字符串，这是最容易踩的差异。

## 三、今天只要记住这 3 句

1. String 不可变：每次拼接都产生新对象，所以循环里用 `+` 拼字符串会生成大量临时对象。
2. `==` 比的是引用地址，`equals` 比的是内容；字符串常量池让字面量可能共享同一对象，所以 `==` 有时对有时错，永远用 `equals`。
3. 切分文档、清洗文本、拼 prompt 全靠字符串操作；Java 里循环拼接必须换 StringBuilder，否则 1 万段文本能把内存打满。

> 今天最容易踩的坑：`split` 的参数是正则，切 `|`、`.`、`*` 必须转义，否则切出来的结果莫名其妙。
