## 五、概念详解

### Java 线 · String 常用 API

#### 1. 字符串不可变与常量池

- **是什么**：String 一旦创建，内容不能修改，所有「修改」都返回新对象。
- **为什么重要**：可安全共享、可做常量池、线程安全；代价是循环拼接会不断创建对象。
- **怎么用 / 坑**：循环里用 `+` 拼 1 万次会生成 1 万个对象，必须换 StringBuilder。
- **今天的最低要求**：能指着 `String 常用 API` 里的具体一行说清它在干什么。

#### 2. length/charAt/substring/indexOf

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。

#### 3. equals 与 == 的区别

- **是什么**：比较两个对象的内容是否相等；`==` 比较的是引用地址。
- **为什么重要**：字符串、包装类、自定义对象的「值相等」判断全靠它。
- **怎么用 / 坑**：自定义类要同时重写 equals 和 hashCode，否则放进 HashMap 会取不出来。

#### 4. trim/replace/split/contains

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。

### Python 线 · 字符串常用方法

#### 1. 切片 s[1:3]、负索引、步长

- **是什么**：按 `[start:stop:step]` 取子序列，左闭右开，支持负索引。
- **为什么重要**：Python 处理字符串和列表最常用的操作，一行替代循环。
- **怎么用 / 坑**：`s[::-1]` 反转，`s[-3:]` 取末三位。注意 stop 不包含，`s[0:3]` 是前三个字符。
- **今天的最低要求**：能指着 `字符串常用方法` 里的具体一行说清它在干什么。

#### 2. split/join/strip/replace

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。

#### 3. startswith/endswith/find

- **这是一组清单**：逐项过一遍，每项只回答两个问题——在哪配置、怎么验证它生效了。
- **落地**：做一张三列表：项目 / 我现在的做法 / 生产环境该怎么改。空着的就是明天要补的。
- **验证**：能说出少做其中哪一项，会引发什么故障。

#### 4. f-string 格式化

- **是什么**：在字符串前加 f，用 `{表达式}` 直接嵌入变量与格式说明。
- **为什么重要**：比 `+` 拼接和 `%` 格式化更可读，也不容易漏空格。
- **怎么用 / 坑**：`f"{price:.2f}"` 保留两位小数，`f"{name:>10}"` 右对齐。表达式里不要塞复杂逻辑。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | Java 的 == 比地址，字符串比较必须用 equals | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |
