### 任务 1｜用 ArrayList 实现一个「待办清单」：增删改查 + 遍历

**Java**（存为 `ListDemo.java`）

```java
import java.util.ArrayList;
import java.util.List;

public class ListDemo {
    public static void main(String[] args) {
        List<String> docs = new ArrayList<>();
        docs.add("rag-intro");
        docs.add("agent-loop");
        docs.add("vector-db");
        docs.add(1, "llm-basic");
        System.out.println("列表: " + docs);
        System.out.println("第 2 个: " + docs.get(1));
        docs.remove("agent-loop");
        System.out.println("删除后: " + docs + " 大小 " + docs.size());
        System.out.println("包含 vector-db: " + docs.contains("vector-db"));
        for (int i = 0; i < docs.size(); i++) {
            System.out.println(i + ": " + docs.get(i));
        }
    }
}
```

```bash
javac ListDemo.java && java ListDemo
```

应该看到：`列表: [rag-intro, llm-basic, agent-loop, vector-db]`

**Python**（存为 `list_demo.py`）

```python
docs = ["rag-intro", "agent-loop", "vector-db"]

print("删除后:", docs, "大小", len(docs))
print("包含 vector-db:", "vector-db" in docs)
for i, d in enumerate(docs):
    print(i, ":", d)
```

```bash
python list_demo.py
```

应该看到：`列表: ['rag-intro', 'llm-basic', 'agent-loop', 'vector-db']`

### 任务 2｜对比 ArrayList 与数组在扩容上的差异

```java
List<Integer> nums = new ArrayList<>(List.of(3, 1, 2));
nums.remove(Integer.valueOf(1));   // 按值删
nums.remove(0);                    // 按下标删
```
```python
nums = [3, 1, 2]
nums.remove(1)      # 按值删，删掉 1
del nums[0]         # 按下标删
```
Java 的 `remove` 有两个重载（int 下标 / Object 值），传 `int` 默认走下标，这是经典坑；Python 的 `remove` 只按值。

## 三、今天只要记住这 3 句

1. `ArrayList` 是可变长数组，查询快（下标 O(1)）、中间插入删除慢（要搬元素）；泛型 `<T>` 让编译器帮你检查类型，避免运行时强转出错。
2. `ArrayList` 有序可重复，`LinkedList` 适合频繁头尾增删但随机访问慢；`List` 是接口，声明时用接口、创建时用实现类。
3. 知识库入库前会用 List 暂存切分后的 chunk，批量写库；用 `LinkedList` 还是 `ArrayList` 取决于你是顺序读还是频繁插队。

> 今天最容易踩的坑：`List<Integer>` 调 `remove(1)` 删的是下标，调 `remove(Integer.valueOf(1))` 删的才是值。
