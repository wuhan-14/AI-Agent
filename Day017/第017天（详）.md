## 五、概念详解

### Java 线 · ArrayList 与泛型入门

#### 1. ArrayList 的增删改查

- **这是接口/注解型知识**：不用背签名。官方文档搜 `ArrayList`，看清它接收什么、返回什么、什么时候不生效。
- **落地**：写一个最小调用（3–5 行）放进 `ArrayList 与泛型入门` 的练习里，跑通一次。
- **验证**：把参数改错或去掉注解，看报什么错。错误信息就是最好的文档。
- **今天的最低要求**：能指着 `ArrayList 与泛型入门` 里的具体一行说清它在干什么。

#### 2. 泛型 <> 的作用

- **是什么**：让类和方法在编译期接受类型参数，如 `List<String>`。
- **为什么重要**：避免到处强转，把类型错误从运行时提前到编译期。
- **怎么用 / 坑**：Java 泛型会擦除，运行时拿不到真实类型；`List<Integer>` 不能赋给 `List<Object>`。

#### 3. ArrayList 与数组的取舍

- **这是接口/注解型知识**：不用背签名。官方文档搜 `ArrayList`，看清它接收什么、返回什么、什么时候不生效。
- **落地**：写一个最小调用（3–5 行）放进 `ArrayList 与泛型入门` 的练习里，跑通一次。
- **验证**：把参数改错或去掉注解，看报什么错。错误信息就是最好的文档。

#### 4. 遍历时删除元素的坑

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

### Python 线 · 列表进阶操作

#### 1. 列表的增删改查与切片赋值

- **是什么**：按 `[start:stop:step]` 取子序列，左闭右开，支持负索引。
- **为什么重要**：Python 处理字符串和列表最常用的操作，一行替代循环。
- **怎么用 / 坑**：`s[::-1]` 反转，`s[-3:]` 取末三位。注意 stop 不包含，`s[0:3]` 是前三个字符。
- **今天的最低要求**：能指着 `列表进阶操作` 里的具体一行说清它在干什么。

#### 2. 列表推导式与过滤

- **是什么**：`[f(x) for x in xs if cond]` 一行生成列表/字典/集合。
- **为什么重要**：比 for + append 更短更快，也更符合 Python 的表达习惯。
- **怎么用 / 坑**：嵌套超过两层就改回循环，否则可读性崩掉。

#### 3. 嵌套列表与排序 key

- **这是对照型知识**：不要背定义，直接列一张表——左边写 A，右边写 B，比较「适用场景 / 代价 / 什么时候不能用」。
- **落地**：在「用 ArrayList 实现一个「待办清单」：增删改查 + 遍历」里各用一次，让两者的差异产生可观察的结果。
- **验证**：能说出「如果我选错了会怎样」，说不出来就还没懂。

#### 4. 浅拷贝与深拷贝

- **是什么**：`copy.copy()` 只复制最外层，内部对象仍是同一引用。
- **为什么重要**：嵌套列表/字典改内层会同时影响原对象。
- **怎么用 / 坑**：需要完全独立用 `copy.deepcopy()`；切片和 `list()` 也是浅拷贝。

## 九、卡住时的排查顺序

| 现象 | 最可能原因 | 第一步查什么 |
| --- | --- | --- |
| 程序起不来 / 报错 | 遍历 ArrayList 时用 remove 会抛 ConcurrentModificationException，要用迭代器 | 先读完整报错，找到第一个 `Caused by` 和自己写的类名 |
| 结果不对但不报错 | 输入不符合预期，或边界没处理 | 在关键位置打印中间值，确认数据在哪一步变错 |
| 照抄示例也跑不通 | 版本/依赖/环境不一致 | 对比版本号；用干净目录重跑一次 |
| 看不懂报错 | 英文术语不熟 | 把报错原文粘到搜索引擎，加上语言和框架名 |
