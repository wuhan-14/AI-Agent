### 任务 1｜手写冒泡排序并对 10 个数排序

**Java**（存为 `SortSearch.java`）

```java
import java.util.Arrays;

public class SortSearch {
    public static void main(String[] args) {
        int[] a = {5, 3, 9, 1, 7};
        Arrays.sort(a);
        System.out.println("排序后: " + Arrays.toString(a));
        int idx = Arrays.binarySearch(a, 7);
        System.out.println("7 的下标: " + idx);

        int[][] m = {{1, 2}, {3, 4}};
        for (int[] row : m) {
            for (int x : row) System.out.print(x + " ");
            System.out.println();
        }
    }
}
```

```bash
javac SortSearch.java && java SortSearch
```

应该看到：`排序后: [1, 3, 5, 7, 9] / 7 的下标: 3`

**Python**（存为 `sort_search.py`）

```python
import bisect

a = [5, 3, 9, 1, 7]
a.sort()
print("排序后:", a)
print("7 的下标:", a.index(7), "bisect:", bisect.bisect_left(a, 7))

m = [[1, 2], [3, 4]]
for row in m:
    print(*row)
```

```bash
python sort_search.py
```

应该看到：`排序后: [1, 3, 5, 7, 9] / 7 的下标: 3 bisect: 3`

### 任务 2｜用二维数组打印一个 3x4 矩阵并求每行和

```java
static void bubble(int[] a) {
    for (int i = 0; i < a.length - 1; i++)
        for (int j = 0; j < a.length - 1 - i; j++)
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            }
}
```
```python
def bubble(a):
    for i in range(len(a) - 1):
        for j in range(len(a) - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a
```
内层上界是 `length - 1 - i`，因为每轮结束最大的元素已经归位，不用再比。写错成 `length - 1` 不报错，只是白跑。

## 三、今天只要记住这 3 句

1. 排序是把无序变有序，查找的快慢取决于是否有序：顺序查找 O(n)，二分查找 O(log n)，但二分只对有序数组有效。
2. 冒泡排序稳定、好理解但 O(n²)，`Arrays.sort` 是双轴快排 + TimSort，工程上直接用；二分查找前必须确认数组已排序。
3. 向量检索的近似最近邻（HNSW）本质就是「在有序/分层的图里快速找最近点」，理解二分才理解为什么要建索引。

> 今天最容易踩的坑：`Arrays.binarySearch` 找不到时返回 `-(插入点) - 1`，不是 -1，直接当下标用会越界。
