### 任务 1｜统计一段文本里不重复的单词数

**Java**（存为 `SetDemo.java`）

```java
import java.util.HashSet;
import java.util.LinkedHashSet;
import java.util.Set;

public class SetDemo {
    public static void main(String[] args) {
        String[] raw = {"rag", "agent", "rag", "llm", "agent"};
        Set<String> uniq = new HashSet<>();
        for (String s : raw) uniq.add(s);
        System.out.println("去重后: " + uniq + " 数量 " + uniq.size());

        Set<String> ordered = new LinkedHashSet<>();
        for (String s : raw) ordered.add(s);
        System.out.println("保持顺序: " + ordered);
        System.out.println("包含 rag: " + uniq.contains("rag"));
        uniq.remove("llm");
        System.out.println("删除后: " + uniq);
    }
}
```

```bash
javac SetDemo.java && java SetDemo
```

应该看到：`去重后: [agent, rag, llm]（顺序不保证）/ 保持顺序: [rag, agent, llm]`

**Python**（存为 `set_demo.py`）

```python
raw = ["rag", "agent", "rag", "llm", "agent"]
uniq = set(raw)
print("去重后:", uniq, "数量", len(uniq))
print("包含 rag:", "rag" in uniq)
uniq.add("vector")
print("新增:", uniq)

words = ["Apple", "apple", "APPLE"]
print("区分大小写:", len(set(words)))
print("忽略大小写:", len({w.lower() for w in words}))
```

```bash
python set_demo.py
```

应该看到：`数量 3 / 区分大小写: 3 忽略大小写: 1`

### 任务 2｜求两个列表的交集、并集、差集

```java
Set<String> a = new HashSet<>(List.of("rag", "agent", "llm"));
Set<String> b = new HashSet<>(List.of("rag", "vector"));
Set<String> inter = new HashSet<>(a); inter.retainAll(b);   // 交集
Set<String> diff = new HashSet<>(a); diff.removeAll(b);     // 差集
```
```python
a = {"rag", "agent", "llm"}
b = {"rag", "vector"}
print(a & b, a - b, a | b)
```
Python 用运算符，Java 用 `retainAll/removeAll`。结果一样，可读性差很多。

## 三、今天只要记住这 3 句

1. `Set` 是不允许重复的集合，判断重复靠 `hashCode` + `equals`；去重、判存在用它，比 List 的 `contains` 快得多。
2. `HashSet` 无序、查询 O(1)；`LinkedHashSet` 保留插入顺序；`TreeSet` 自动排序、O(log n)。要顺序选 Linked，要排序选 Tree。
3. 去重是 RAG 的常见动作：多路召回合并后必须去重，否则同一段文本进上下文两次，既费 token 又干扰模型判断。

> 今天最容易踩的坑：改写 `equals` 必须同时改写 `hashCode`，只改一个会让 HashMap/HashSet 行为错乱。
