## 五、概念详解

### Java 线 · Set 家族

#### 1. HashSet 的去重原理（hashCode + equals）

- **是什么**：比较两个对象的内容是否相等；`==` 比较的是引用地址。
- **为什么重要**：字符串、包装类、自定义对象的「值相等」判断全靠它。
- **怎么用 / 坑**：自定义类要同时重写 equals 和 hashCode，否则放进 HashMap 会取不出来。
- **今天的最低要求**：能指着 `Set 家族` 里的具体一行说清它在干什么。

#### 2. LinkedHashSet 保留插入顺序

- **这是接口/注解型知识**：不用背签名。官方文档搜 `LinkedHashSet`，看清它接收什么、返回什么、什么时候不生效。
- **落地**：写一个最小调用（3–5 行）放进 `Set 家族` 的练习里，跑通一次。
- **验证**：把参数改错或去掉注解，看报什么错。错误信息就是最好的文档。

#### 3. TreeSet 自动排序

- **这是接口/注解型知识**：不用背签名。官方文档搜 `TreeSet`，看清它接收什么、返回什么、什么时候不生效。
- **落地**：写一个最小调用（3–5 行）放进 `Set 家族` 的练习里，跑通一次。

### Python 线 · 集合 set

#### 1. set 去重与成员判断

- **是什么**：不重复元素的无序集合，底层哈希表。
- **为什么重要**：去重和「是否存在」判断的最快方案，比 list 的 `in` 快一个量级。
- **怎么用 / 坑**：`a & b` 交集、`a | b` 并集。空集合写 `set()`，`{}` 是空字典。
- **今天的最低要求**：能指着 `集合 set` 里的具体一行说清它在干什么。

#### 2. 集合运算 & | -

- **这是结论型知识**：这句话本身就是要记住的判断，重点是「为什么是这样」。
- **落地**：在今天的示例代码里找出对应的一行，把它注释掉再运行，观察差异。
- **验证**：想一个反例（什么情况下这句话不成立），想不出来说明理解还停留在表面。

#### 3. 空集合写 set()

- **是什么**：不重复元素的无序集合，底层哈希表。
- **为什么重要**：去重和「是否存在」判断的最快方案，比 list 的 `in` 快一个量级。
- **怎么用 / 坑**：`a & b` 交集、`a | b` 并集。空集合写 `set()`，`{}` 是空字典。

#### 4. 可哈希才能放进 set

- **是什么**：不重复元素的无序集合，底层哈希表。
- **为什么重要**：去重和「是否存在」判断的最快方案，比 list 的 `in` 快一个量级。
- **怎么用 / 坑**：`a & b` 交集、`a | b` 并集。空集合写 `set()`，`{}` 是空字典。
